# Портфолио

Одностраничный сайт-портфолио: HTML, CSS и немного JavaScript, без сборки.

Сайт: https://web-portfolio-ru.netlify.app

## Посмотреть локально

```bash
python3 -m http.server 4321
# открыть http://localhost:4321
```

## Добавить новую работу

1. Скриншоты положите в `img/`: первый экран `имя-d-1920.webp` и `имя-d-960.webp` (1440×900),
   телефон `имя-m-640.webp` (390×844), второй кадр `имя-x-1920.webp` и `имя-x-960.webp`.
2. В `index.html` скопируйте блок `<article class="case">`.
   Цвет подложки задаётся в `style="--mat:…"`. Чередуйте класс `case--flip`, чтобы телефон был то справа, то слева.

## Публикация

Обновить сайт на Netlify: `netlify deploy --prod --dir .` из этой папки.
Файл `_headers` добавляет заголовки безопасности и кэширование.
